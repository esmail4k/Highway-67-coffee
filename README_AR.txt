HIGHWAY 67 COFFEE — الإصدار السادس (نظام طلبات متصل بقاعدة بيانات)

التشغيل:
1) تحتاج Python 3.10+ على كمبيوتر. فك ضغط الملف.
2) Windows: شغّل start_windows.bat (أو py -m pip install -r requirements.txt ثم py run_local.py).
   macOS/Linux: شغّل start_mac_linux.sh (أو python3 -m pip install -r requirements.txt ثم python3 run_local.py).
3) أدخل كلمة مرور الموظف والمالك عند الطلب. لا تُحفظ كلمات المرور داخل الكود.
   أسماء المستخدمين: الموظف admin123 — المالك esmail (قابلة للتغيير بمتغيرات البيئة).
4) افتح الروابط التي تظهر في نافذة التشغيل:
   الزبائن: http://127.0.0.1:8080/
   الموظفون: http://127.0.0.1:8080/staff
   المالك: http://127.0.0.1:8080/owner
5) افتح صفحة الموظف، وسجل الدخول ثم اضغط «بدء يوم جديد». الآن يستطيع الزبون إرسال طلب.

التغييرات الأساسية:
- الموقع ليس صورة أو محاكاة. كل طلب يُحفظ فعلياً في قاعدة بيانات SQLite المحلية data/highway67.sqlite3.
- العميل يضيف للسلة ويحذف منتجاً محدداً أو يفرغ السلة، ثم يؤكد الطلب باسمه وهاتفه ورقم السيارة وملاحظاته.
- تظهر علامة النجاح ورقم الطلب بعد إتمام التسجيل الفعلي في قاعدة البيانات فقط.
- الموظف يرى الفاتورة، يحدد «جاهز» ثم «تم التسليم»، ويتابع الزمن والمبيعات والأيام السابقة.
- «إنهاء اليوم» يُغلق سجل يوم العمل وينقل بياناته إلى الأرشيف، وتصير شاشة اليوم صفر. يبدأ يوم جديد فقط بضغط «بدء يوم جديد».
- في حال وجود طلبات لم تُسلّم وقت الإغلاق، يظهر زر تأكيد إضافي: تُلغى الطلبات المعلقة وتبقى موثقة في اليوم المؤرشف.
- المالك يستطيع حذف فاتورة محددة بتأكيد ثانٍ؛ يتحدث إجمالي المبيعات مباشرة، وكذلك حذف/استرجاع الأيام.
- يستطيع المالك أيضاً تعديل المنتجات وأسعارها وصورها، والتوفر والخصومات والعروض المحددة بالوقت.
- لا تظهر أي رسائل داخل واجهة الزبائن عن «نسخة تجريبية» أو «أسعار مؤقتة».

مهم قبل استقبال زبائن فعليين:
- بعض الأسعار الواردة في الصور المرجعية ليست قائمة أسعار معتمدة؛ راجعها وعدّلها من لوحة المالك.
- التشغيل المحلي متاح للمتصفح على نفس الكمبيوتر فقط، وليس رابطاً عاماً للزبائن.
- للنشر العام يلزم HTTPS، استضافة دائمة تحفظ قاعدة البيانات والصور، ونسخ احتياطية، وإعدادات خصوصية مناسبة لبيانات العملاء.
- لا تُنشر كلمات المرور الضعيفة القديمة في الملفات العامة أو المستودعات.
- رمز QR المطبوع الحالي يوجّه إلى https://highway67-coffee-photo-menu.onrender.com/ ولا يوجد تغيير على هذا الرابط في الحزمة.
- هذه الحزمة لم تُرفع إلى استضافة رابط QR؛ لذلك الرابط المباشر الحالي ما زال يعمل بالنسخة السابقة.
